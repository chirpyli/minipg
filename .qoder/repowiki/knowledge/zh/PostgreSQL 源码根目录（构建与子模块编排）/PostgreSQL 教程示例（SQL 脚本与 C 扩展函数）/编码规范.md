- 每个 C 函数通过 PG_FUNCTION_INFO_V1(函数名) 宏显式注册，并使用 PG_GETARG_* 系列宏读取参数、PG_RETURN_* 系列宏返回结果。
- 自定义类型（如 Complex）配套实现 *_in/*_out 文本 I/O 与可选的 *_recv/*_send 二进制 I/O，遵循 PostgreSQL 用户定义类型的标准接口约定。
- B-tree 操作符族（lt/le/eq/ge/gt/cmp）统一委托给一个内部静态比较函数（如 complex_abs_cmp_internal），以保证各比较语义的一致性。
- 动态分配的内存一律通过 palloc 分配、ereport(ERROR, ...) 报告错误，避免直接 malloc/free。
- SQL 教程脚本以 .source 模板形式编写，借助 Makefile 的 sed 规则将 _OBJWD_ 占位符替换为当前工作目录后生成最终可执行的 .sql 文件。
