本模块是 PostgreSQL 源码树中的教学示例目录，由两类产物组成：
- SQL 教程脚本：basics.source、advanced.source、complex.source、funcs.source、syscat.source 为 .source 模板文件，通过 Makefile 的 %.sql: %.source 规则经 sed 替换 _OBJWD_ 占位符生成对应的 .sql 输出，供 psql -s 单步执行。
- C 扩展函数库：funcs.c 实现按值/按引用传递的基础函数（如 add_one、makepoint、copytext、concat_text、c_overpaid），complex.c 定义自定义 Complex 数据类型及其输入/输出、二进制收发、算术运算符以及基于幅值的 B-tree 比较操作符族（complex_abs_lt/le/eq/ge/gt/cmp）。
构建通过顶层 Makefile 声明 MODULES = complex funcs 并依赖 PGXS（或 NO_PGXS=1 时使用源码树内构建），所有 C 函数统一以 PG_FUNCTION_INFO_V1 宏注册并通过 Datum + PG_GETARG_* / PG_RETURN_* 宏与后端交互，模块入口均包含 PG_MODULE_MAGIC。
