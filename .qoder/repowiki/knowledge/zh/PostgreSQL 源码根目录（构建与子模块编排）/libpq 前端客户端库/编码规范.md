- 公共 API 通过 libpq-fe.h 暴露 opaque 句柄（PGconn、PGresult、PGcancel 等 struct 仅 typedef 不定义成员），具体结构体实现在 libpq-int.h 中对外隐藏。
- 所有对外的 C 函数名统一以 PQ 前缀命名（如 PQconnectdb、PQexec、PQfinish 等），并在 exports.txt 中以固定序号登记以维护 ABI 稳定性。
- 源码按功能域拆分到 fe-*.c 文件（连接、协议、认证、执行、打印、追踪、安全），每个文件聚焦单一职责并通过 libpq-int.h 共享内部类型。
- 构建系统通过 Makefile.global + Makefile.shlib 模板化编译，OBJS 列表集中声明参与链接的对象文件，平台差异通过 PORTNAME 条件分支添加 win32/pthread-win32 等对象。
