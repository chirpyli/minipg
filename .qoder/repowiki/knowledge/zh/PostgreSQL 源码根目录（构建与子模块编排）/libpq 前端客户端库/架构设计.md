本模块为 PostgreSQL 的 C 客户端库 libpq，按职责拆分为多个源文件：fe-connect.c 负责连接建立（含非阻塞连接状态机），fe-protocol3.c 实现 v3 协议消息编解码，fe-auth.c 处理 md5/SCRAM 等认证流程，fe-exec.c 管理查询执行与 PGresult，fe-print.c/pqexpbuffer.c 负责结果打印与动态缓冲区，fe-trace.c 提供调试跟踪，libpq-events.c 实现应用可注册的连接/结果事件钩子；公共头 libpq-fe.h 暴露稳定 API（PGconn、PGresult、PGcancel 等 opaque 句柄及 PQ* 函数族），内部头 libpq-int.h 和 pqexpbuffer.h 仅供库内使用。构建产物为共享库 libpq.so（版本由 Makefile 中的 SO_MAJOR_VERSION/SO_MINOR_VERSION 控制），通过 exports.txt 显式声明导出符号表以控制 DLL 接口；依赖 pgcommon_shlib 与 pgport_shlib，并通过 SHLIB_LINK_INTERNAL 注入。顶层 Makefile 仅作为子目录入口递归进入 libpq/ 并安装头文件到 includedir/includedir_internal。
