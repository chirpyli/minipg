顶层 configure.ac + aclocal.m4 完成平台检测并生成 config.status，再由 GNUmakefile.in 通过 $(call recurse,...) 宏按 src → contrib → doc 的顺序递归驱动各子目录 Makefile；src/ 内部再细分为 backend_server、client_tools、common_libs、interfaces、headers、timezone 等子模块，contrib_extensions 作为可选扩展在 world/world-bin 目标中于 src 之后构建，tests 通过 check-world/installcheck-world 依赖已安装的 bin/lib 运行回归测试，documentation 提供 SGML 文档构建入口。裁剪后的代码树移除了 ecpg 等组件，但仍保持原 PostgreSQL 的分层调用链与共享头文件契约。
