- 每个子目录的 Makefile 均继承顶层 `src/Makefile.global`，并通过 `override CPPFLAGS := -I... -DFRONTEND ...` 统一注入前端宏与包含路径。
- common 与 port 采用“单源三态”构建模式：同一份 `.c` 同时编译出普通 `.o`、`*_shlib.o`（追加 `CFLAGS_SL`）和 `*_srv.o`（从 `CPPFLAGS` 中剔除 `-DFRONTEND`），分别归档到不同静态库。
- 平台无关逻辑放在 `src/common/`，系统调用/缺失函数的可移植适配放在 `src/port/`，前端专用 UI/交互逻辑放在 `src/fe_utils/`，三者职责边界清晰且单向依赖。
- CPU 特化代码（如 CRC32C）以独立文件提供多种实现，并通过 `*_choose.c` 选择器在运行时根据检测到的指令集选择最优版本。
- 需要外部数据表的模块（keywords、unicode 规范化）通过 Perl 脚本在构建期生成 C 头文件或表，并将生成的文件纳入版本控制以便非维护者也能正常构建。
