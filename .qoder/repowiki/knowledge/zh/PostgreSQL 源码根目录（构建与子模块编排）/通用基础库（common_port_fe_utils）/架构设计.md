本模块由三个相互独立的子目录组成，每个子目录通过各自的 Makefile 构建出独立的静态库，被上层 backend、libpq 及 contrib 复用：
- `src/common/`：核心公共库，按用途划分为字符串与内存（string.c/stringinfo.c/fe_memutils.c）、数值编解码（d2s.c/f2s.c，基于 Ryu）、加密摘要（md5/sha1/sha2/hmac/cryptohash）、文件系统与路径（file_utils.c/rmtree.c/relpath.c）、网络与 IP（ip.c）、JSON API（jsonapi.c）、关键字查找（keywords.c/kwlookup.c）、Unicode 规范化（unicode_norm.c + unicode/ 生成表）等。Makefile 将源码编译为三套目标：`libpgcommon.a`（定义 FRONTEND，供客户端）、`libpgcommon_shlib.a`（加 -fPIC 风格的 CFLAGS_SL，供共享库）、`libpgcommon_srv.a`（去掉 -DFRONTEND，仅后端使用），通过 `%_srv.o` / `%_shlib.o` 模式规则从同一份 .c 派生。
- `src/port/`：平台移植层，实现 POSIX/glibc 缺失或行为不一致的函数（strlcpy/strlcat/getopt/inet_aton/mkdtemp/pread/pwrite/pgsleep/pgmkdirp 等），并包含 CPU 特化的 CRC32C 实现（sse42/armv8 选择器）。同样产出 `libpgport.a` / `_shlib.a` / `_srv.a` 三件套，并通过 configure 探测的 `LIBOBJS` 与 `PG_CRC32C_OBJS` 条件性纳入对象。
- `src/fe_utils/`：面向前端（psql/libpq）的工具库，封装归档、取消、条件打印、多字节字符输出、SQL 扫描（psqlscan.l → psqlscan.c）等，仅构建单一 `libpgfeutils.a`，并依赖 libpq 头（`$(libpq_srcdir)`）。
依赖方向自下而上：fe_utils → common/port；common 与 port 之间无直接依赖，仅通过统一的 `-DFRONTEND` 宏区分前后端语义。
