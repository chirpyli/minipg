本模块是 PostgreSQL 的前端（frontend）可执行程序集合，由顶层 src/bin/Makefile 通过 SUBDIRS 统一递归构建 initdb、pg_config、pg_controldata、pg_ctl、pg_rewind、pg_waldump、psql 七个独立子程序。每个子目录自包含 Makefile、C 源码及 t/*.pl TAP 测试脚本，遵循 PG 标准构建约定：声明 PGFILEDESC、include src/Makefile.global、通过 LDFLAGS_INTERNAL 链接 libpgport/libpq/libpgfeutils 等共享库。

- 依赖方向：所有工具均定义 -DFRONTEND，仅依赖后端提供的公共头与 libpgport/libpq/libpgfeutils，不反向依赖后端对象；pg_waldump/pg_rewind 通过符号链接方式复用 backend/access/transam/xlogreader.c 以复用 WAL 解析逻辑。
- 内部分层：psql 按功能拆分为 command/input/prompt/mainloop/help/describe/crosstabview/tab-complete/variables/stringutils 等 .c/.h 对；pg_rewind 将数据页映射、文件操作、文件图、时间线、日志解析抽象为 datapagemap/file_ops/filemap/timeline/parsexlog 等模块，并通过 rewind_source.h 接口在 local_source 与 libpq_source 之间切换数据源。
- 代码生成：psql 使用 flex (psqlscanslash.l) 生成 psqlscanslash.c，并通过 create_help.pl 扫描 doc/src/sgml/ref/*.sgml 生成 sql_help.h/sql_help.c；pg_waldump 动态收集 backend/access/rmgrdesc/*desc.c 编译 RMGRDESCOBJS 以支持多种 WAL 记录类型描述。
- 平台适配：各 Makefile 通过 $(WIN32RES)、ifeq ($(PORTNAME), win32) 处理 Windows 资源与 libpq 链接差异。
