- 回归测试采用 `sql/<name>.sql` 输入与 `expected/<name>.out` 期望输出一一对应的命名约定，新增用例需在 `parallel_schedule` 或 `standby_schedule` 中注册。
- 隔离测试以 `.spec` 文件定义 setup/teardown/session/step/permutation，并在 `specs/` 下新增后同步更新 `isolation_schedule` 与 `expected/<name>.out`。
- Perl TAP 测试统一以 `use PostgresNode; use TestLib; use Test::More tests => N;` 开头，通过 `PostgresNode->get_new_node` 管理实例生命周期。
- 测试扩展遵循标准 PostgreSQL 扩展布局：`<ext>.control` 元数据、`<ext>--1.0.sql` 安装脚本、`sql/` 测试 SQL 与 `expected/` 期望输出并存于同一扩展目录。
- 每个测试子目录均自带独立 `Makefile`，由顶层 `src/test/Makefile` 递归聚合，避免在顶层维护分散的构建规则。
