本模块是 PostgreSQL 的顶层测试集合，按测试类型划分为多个相互独立的子目录：
- `regress/`：基于 `pg_regress` 的主回归测试框架，包含 `pg_regress.c`、`Makefile`、`parallel_schedule`/`standby_schedule` 调度文件，以及成对的 `sql/*.sql`（输入）与 `expected/*.out`（期望输出），通过 `data/` 中的种子数据驱动。
- `isolation/`：针对并发/隔离级别的专用测试，由 `isolationtester.c` + `isolation_main.c` 驱动，使用自定义 DSL 的 `.spec` 文件描述会话、步骤与排列（permutation），并通过 `specparse.y` / `specscanner.l` 解析；`expected/` 存放每个 spec 的期望输出。
- `perl/`：共享 Perl 测试库（`PostgresNode.pm`、`TestLib.pm`、`RecursiveCopy.pm`、`SimpleTee.pm` 等），被各子树中基于 `prove` 的 TAP 测试复用。
- `recovery/`、`locale/`、`mb/`、`postmaster/`：分别覆盖恢复/复制、区域设置/编码、多字节编码、后端进程等专项测试，各自带独立 Makefile 与 `expected/` 结果集。
- `modules/`：仅用于测试的 PostgreSQL 扩展集合（如 `test_bloomfilter`、`worker_spi`、`commit_ts`、`dummy_index_am` 等），每个扩展自带 `*.control`、`--1.0.sql` 安装脚本及对应的 `sql/` + `expected/` 或 `t/*.pl` 用例。
- `examples/`：libpq 示例程序（`testlibpq.c` 等），既作为演示也作为回归用例。
依赖方向自底向上：`modules/*` 扩展被上层 `regress`/`isolation`/`recovery` 等用例加载调用；`perl/` 为所有 Perl TAP 测试提供公共节点管理与 psql 封装；顶层 `src/test/Makefile` 聚合各子目录的 check/installcheck 目标。
