该模块是 PostgreSQL 的公共/内部头文件根目录，采用按子系统划分的扁平目录结构：顶层放置跨进程共享的基础头（postgres.h、c.h、pg_config*.h、fmgr.h、funcapi.h），各子目录对应一个子系统——access（访问方法/TOAST/XLOG）、catalog（系统目录定义 .dat/.h 对）、commands（SQL 命令入口）、common（前后端通用工具）、datatype（数据类型）、executor（执行器节点）、lib（通用数据结构如 binaryheap/rbtree/simplehash）、libpq（客户端协议接口）、mb（多字节字符集）、nodes（解析树/计划树/执行树节点）、optimizer（优化器）、parser（语法分析）、port/portability（平台抽象）、postmaster（后台进程）、replication/rewrite/statistics/storage/tcop/utils（存储、事务、工具等）。Makefile 通过 SUBDIRS 枚举所有可安装子目录，install 目标将 *.h 复制到 includedir_server，并将 pg_config.h/pg_config_ext.h/pg_config_os.h/postgres_ext.h 等作为公共接口头安装到 includedir；同时依赖 build 过程生成 parser/gram.h、catalog/schemapg.h、catalog/pg_*_d.h、utils/fmgroids.h、utils/probes.h、storage/lwlocknames.h 等由脚本或 bison/yacc 生成的头文件，clean 目标负责清理这些产物。依赖方向严格自顶向下：postgres.h → c.h → pg_config*.h → 各子系统头，子系统之间通过 include 相对路径引用，禁止循环包含。
