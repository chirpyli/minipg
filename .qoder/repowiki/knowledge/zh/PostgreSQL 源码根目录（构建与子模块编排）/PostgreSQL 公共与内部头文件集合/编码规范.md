- 每个子系统头文件位于与其功能同名的子目录下，并通过相对路径 `#include "subdir/file.h"` 引用其他头，避免绝对路径。
- 系统目录（catalog）采用 .dat 数据描述文件与同名 .h 头一一对应的模式，由 Perl 脚本从 .dat 生成 *_d.h 供后端直接 include。
- 平台相关代码集中在 port/ 与 port/atomics/ 下，通过 #ifdef HAVE_* 或编译器检测在 c.h 中统一暴露为 pg_attribute_*、pg_always_inline 等宏。
- 构建期生成的头（gram.h、schemapg.h、probes.h、fmgroids.h、lwlocknames.h 等）在 Makefile 的 clean/distclean 目标中显式列出以便清理。
- 头文件普遍使用 `#ifndef FILE_H / #define FILE_H / ... / #endif` 形式的 include guard，且 postgres.h、c.h 等核心头作为所有后端的单一入口被首先包含。
- 公共 API 与内部实现分离：postgres_ext.h、pg_config*.h 安装到 $includedir（外部可用），而 c.h、port.h、postgres_fe.h、libpq/pqcomm.h 安装到 $includedir_internal（仅后端/前端内部使用）。
