本模块是 PostgreSQL 对 IANA tzcode/tzdata 的移植与裁剪：
- 核心 C 源文件构成运行时库：`localtime.c` 实现 `localtime_r`/`mktime` 等转换逻辑；`strftime.c` 提供 `strftime` 兼容实现；`pgtz.c` 封装时区文件打开、解析与缓存，并通过 `pgtz.h` 暴露 `pg_open_tzfile`、`tzload`、`tzparse` 等接口供后端调用。
- 构建产物分为两类：后端对象文件（`OBJS = localtime.o pgtz.o strftime.o`）链接进 server；独立工具 `zic`（由 `zic.c` 编译）用于将 `data/tzdata.zi` 编译为二进制时区数据并安装到 `$(datadir)/timezone`。
- 数据层：`data/tzdata.zi` 是 IANA 时区数据的压缩单文件版本；`tznames/` 目录维护按地区划分的缩写模板（Africa.txt、America.txt 等）以及可被 `timezone_abbreviations` 参数选用的自定义集合（Default、Australia、India），通过 `tznames/Makefile` 安装到 `$(datadir)/timezonesets`。
- 头文件分层：`private.h` 提供 PG 适配的公共宏（如 `pg_time_t`、`is_leap`、TIME_T_MIN/MAX）；`pgtz.h` 定义内部结构体 `ttinfo`、`lsinfo`、`state`、`pg_tz` 及对外 API；`tzfile.h` 描述 TZif 文件格式。
- 依赖方向：`pgtz.c` → `localtime.c` → `private.h`/`pgtime.h`；`zic.c` 仅用于构建期生成数据，不被运行时链接；`strftime.c` 自包含，不依赖 `pgtz`。
