- 每个 .c 文件顶部包含标准 PostgreSQL 版权声明与 IDENTIFICATION 注释块，标明源码路径。
- 对系统目录（pg_rewrite、pg_class）的操作统一使用 table_open + RowExclusiveLock/AccessExclusiveLock，并在结束时调用 table_close(NoLock) 保持事务锁。
- 通过 SearchSysCache* / SearchSysCacheExists2 访问系统缓存，配合 CatalogTupleInsert/Update/Delete 完成元数据变更。
- 错误报告统一使用 ereport(ERROR, ...) 并附带 errcode/errmsg/errhint，区分 FEATURE_NOT_SUPPORTED、INVALID_OBJECT_DEFINITION 等语义化错误码。
- 公共函数在对应 rewrite*.h 头文件中声明，内部静态函数以 static 修饰并按功能分组放置于文件顶部。
- 涉及关系或规则变更时，通过 CacheInvalidateRelcache / SetRelationRuleStatus 触发共享内存失效通知，确保多后端 relcache 一致性。
