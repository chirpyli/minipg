模块按职责拆分为五个 C 源文件，通过 Makefile 统一编译为 rewrite 子系统的目标文件：
- rewriteDefine.c：定义 CREATE RULE / ALTER RULE 的入口 DefineRule、DefineQueryRewrite 与 EnableDisableRule，完成权限校验、ON SELECT 视图转换、pg_rewrite 系统表写入及依赖记录。
- rewriteHandler.c：重写引擎主循环 RewriteQuery，遍历 Relation 上的 RuleLock，按事件类型匹配并展开 rule action，处理 RIR（Retrieve-Instead-Retrieve）规则、锁获取、JOIN RTE 调整等核心逻辑。
- rewriteManip.c：提供 Query/表达式树操作工具，如 contain_aggs_of_level、locate_agg_of_level、checkExprHasSubLink 等 walker 辅助函数。
- rewriteRemove.c：实现 RemoveRewriteRuleById，从 pg_rewrite 删除规则并广播 relcache 失效。
- rewriteSupport.c：暴露 IsDefinedRewriteRule、SetRelationRuleStatus、get_rewrite_oid 等跨模块共享的轻量工具。
依赖方向单向：rewriteHandler → rewriteManip/rewriteSupport；rewriteDefine 依赖 rewriteManip/rewriteSupport；rewriteRemove 独立但与其他模块通过 pg_rewrite 系统表交互。所有文件均包含 postgres.h 并通过 rewrite/*.h 头文件暴露接口，遵循 PostgreSQL 后端 common.mk 构建约定。
