本模块是后端 `access/index` 子系统的核心层，按职责拆分为四个编译单元：
- `indexam.c`：暴露 `index_open/close/beginscan/rescan/endscan/insert/bulk_delete/vacuum_cleanup` 等高层 `index_*` API，封装对具体 IndexAM 的调用，并通过 `RELATION_CHECKS`、`SCAN_CHECKS`、`CHECK_REL_PROCEDURE` 等宏在每次调用前校验 Relation/Scan 有效性及 AM 钩子是否实现。
- `genam.c`：提供所有索引 AM 共享的通用结构体与流程，如 `RelationGetIndexScan/IndexScanEnd` 分配释放 `IndexScanDesc`、`BuildIndexValueDescription` 构造错误消息等，是各具体 AM（btree/hash/gin/gist 等）必须调用的基座。
- `amapi.c`：通过 `pg_am` 系统目录查找 AM handler OID 并调用其返回 `IndexAmRoutine` 结构，暴露 `GetIndexAmRoutine` / `GetIndexAmRoutineByAmId` / `amvalidate` 供 relcache 与 DDL 路径在引导期安全使用。
- `amvalidate.c`：实现 `identify_opfamily_groups`、`check_amproc_signature`、`check_amoptsproc_signature` 等工具，用于验证操作符族中 operator/support function 的类型签名与策略位集。
依赖方向单向向下：本模块依赖 `catalog/*`、`storage/*`、`utils/syscache.h`、`access/amapi.h`、`access/genam.h`，被上层查询执行器与 DDL 子系统调用；构建产物由 `Makefile` 汇总为 `amapi.o amvalidate.o genam.o indexam.o`，并通过 `common.mk` 链接到后端可执行文件。
