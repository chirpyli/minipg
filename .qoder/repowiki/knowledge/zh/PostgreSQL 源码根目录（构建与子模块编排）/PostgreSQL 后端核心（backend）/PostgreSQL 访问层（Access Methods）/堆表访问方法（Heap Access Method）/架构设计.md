本模块是 PostgreSQL 的默认堆表访问方法实现，按职责拆分为多个源文件并通过 Makefile 统一编译为共享对象：
- heapam.c：堆 AM 的核心 I/O 与事务语义层，实现 heap_insert/update/delete/fetch/scan 等接口，处理 MVCC 可见性、MultiXact 锁、HOT 链跟随、索引删除协调。
- heapam_handler.c：将底层 heapam_* 函数包装成 TableAmRoutine 结构体，向上暴露统一的 table access method 抽象，并实现 index_fetch/slot/syncscan 等回调。
- hio.c：页面级元组 I/O，封装 RelationPutHeapTuple、ReadBufferBI、RelationAddExtraBlocks 等缓冲与批量插入逻辑。
- heapam_visibility.c / visibilitymap.c：可见性判断与可见性映射（VM）操作，配合 PageIsAllVisible 与 VM 位图加速全可见页判定。
- pruneheap.c：页内元组修剪（page-level pruning），压缩 HOT 链、回收死元组与重定向 line pointer。
- vacuumlazy.c：惰性 VACUUM 实现，按页扫描并触发 prune/defragmentation。
- rewriteheap.c：CLUSTER/REINDEX/VACUUM FULL 等重写场景下的元组改写与重建。
- heaptoast.c：TOAST 大字段与堆表的集成，处理 out-of-line 值存取。
依赖方向自下而上：hio → heapam → heapam_handler；各子模块通过 access/ 目录下的公共头（access/heapam.h、access/hio.h、access/visibilitymap.h、access/multixact.h 等）协作，不直接互相包含，保持清晰边界。Makefile 中 OBJS 列表即模块产物清单，顶层 common.mk 负责链接。
