本目录是 `src/backend/access` 的顶层 Makefile，通过 `SUBDIRS = common hash heap index nbtree rmgrdesc table tablesample transam` 统一编排各子模块的编译顺序与链接。
- 依赖方向自底向上：`common` 提供元组、TOAST、扫描键等基础工具；`table` 提供独立于具体 AM 的表关系与槽接口；`index` 定义 IndexAM 框架；`heap`、`nbtree`、`hash` 分别实现表访问方法与两种索引访问方法；`transam` 提供 WAL/XLOG、SLRU、两阶段提交等持久化基础设施；`rmgrdesc` 为各 rmgr 提供 WAL 记录文本描述；`tablesample` 通过 TsmRoutine 向执行器暴露采样扫描。
- 跨子模块协作契约：具体 AM（heap/nbtree/hash）通过 `tableam.c` 暴露 TableAmRoutine、通过 `index/amapi.c` 暴露 IndexAmRoutine，被上层 executor/planner 调用；所有写路径经 `transam` 生成 WAL，并由 `rmgrdesc` 在回放或 pg_waldump 时解析；`common` 中的 heaptuple/tupdesc/scankey/toast 等结构被多个 AM 共享。
- 每个子目录自带独立 Makefile 与 objfiles.txt，顶层仅负责汇总，使新增访问方法只需追加子目录并列入 SUBDIRS。
