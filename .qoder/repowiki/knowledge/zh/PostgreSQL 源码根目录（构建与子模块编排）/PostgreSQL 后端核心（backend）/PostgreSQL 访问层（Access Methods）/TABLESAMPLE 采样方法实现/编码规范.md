- 每个采样方法以 tsm_xxx_handler(PG_FUNCTION_ARGS) 形式导出，构造 TsmRoutine 节点并填充 parameterTypes、repeatable_across_* 标志及各回调函数指针。
- 采样状态封装在文件内私有结构体（SystemSamplerData/BernoulliSamplerData）中，通过 node->tsm_state 在 Init/Begin/Next 回调间传递。
- BEGIN 阶段对百分比参数进行 0~100 范围与 isnan 校验，失败时抛出 ERRCODE_INVALID_TABLESAMPLE_ARGUMENT。
- 使用 hash_any 对 (blockno, seed) 或 (blockno, offset, seed) 输入计算 uint32 哈希，并与根据百分比换算出的 uint64 cutoff 比较来决定是否选中目标。
- 样本大小估计通过 SampleScanGetSampleSize 回调完成，优先从 Const 参数提取 samplefract，否则回退到默认 0.1f，并用 clamp_row_est 限制结果。
- NextSampleTuple 在未找到匹配项时返回 InvalidOffsetNumber 通知上层切换到下一块，并在回调末尾更新 lt 字段以保持迭代位置。
