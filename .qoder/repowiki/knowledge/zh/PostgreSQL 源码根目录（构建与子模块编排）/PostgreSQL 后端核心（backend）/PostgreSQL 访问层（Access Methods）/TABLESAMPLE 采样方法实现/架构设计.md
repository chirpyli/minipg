本模块是 access/tsm 框架的具体采样策略插件，由 Makefile 将 bernoulli.c、system.c、tablesample.c 编译为后端共享对象的一部分。
- tablesample.c：仅提供 GetTsmRoutine() 辅助函数，通过 OidFunctionCall1 调用注册 handler 并校验返回的 TsmRoutine 指针，是外部与具体采样方法之间的统一入口。
- system.c：实现 SYSTEM 块级采样，tsm_system_handler 构造 TsmRoutine，设置 NextSampleBlock/NextSampleTuple；使用 hash_any(blockno, seed) 与 cutoff 比较决定哪些数据块被采样，状态保存在 SystemSamplerData 中。
- bernoulli.c：实现 BERNOULLI 元组级采样，tsm_bernoulli_handler 构造 TsmRoutine，仅实现 NextSampleTuple（NextSampleBlock 置 NULL）；对每个 (blockno, offset, seed) 三元组做哈希并与 cutoff 比较决定是否选中该元组。
- 两个方法均遵循相同生命周期：InitSampleScan → BeginSampleScan（参数校验、计算 cutoff/seed）→ NextSampleBlock/NextSampleTuple 迭代 → EndSampleScan（可选）；估计阶段通过 SampleScanGetSampleSize 回调向规划器报告 pages/tuples 期望值。
- 依赖方向单向指向上层 tsmapi（access/tsmapi.h）、relscan、optimizer、common/hashfn，不反向依赖任何 tablesample 内部文件。
