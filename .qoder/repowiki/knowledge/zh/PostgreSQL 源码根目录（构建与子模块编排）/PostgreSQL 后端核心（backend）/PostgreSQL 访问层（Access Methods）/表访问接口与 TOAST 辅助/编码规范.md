- 表关系打开 API 成对出现（如 table_open / try_table_open、table_openrv / table_openrv_extended），后者通过 missing_ok 或返回 NULL 表达“不存在”语义，并在内部统一校验 relkind 是否为 index/composite type。
- 所有表级操作通过 Relation->rd_tableam 指向的函数指针分派到具体存储方法，本模块仅提供与具体 AM 无关的统一入口。
- TOAST 相关逻辑围绕 ToastTupleContext 结构体组织，先初始化 ttc_attr/ttc_flags 再根据列属性与大小进行压缩/外存决策，INSERT 与 UPDATE 共用同一套准备流程。
- 常量集中定义在 .c 文件顶部（如 PARALLEL_SEQSCAN_NCHUNKS、PARALLEL_SEQSCAN_RAMPDOWN_CHUNKS 等），并以大写命名区分于普通变量。
- 每个源文件以 PostgreSQL 标准版权头与 IDENTIFICATION 注释开头，并按功能用注释块（如 Slot functions、Table scan functions）划分段落。
