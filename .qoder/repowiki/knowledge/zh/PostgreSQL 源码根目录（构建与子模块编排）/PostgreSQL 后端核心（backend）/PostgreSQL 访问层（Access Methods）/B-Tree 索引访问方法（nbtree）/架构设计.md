模块以 `nbtree.c` 中的 `bthandler()` 为入口，构造并返回 `IndexAmRoutine`，将 `btinsert/btbeginscan/btgettuple/btbulkdelete/btvacuumcleanup/btvalidate` 等回调注册到 Postgres 索引访问方法框架，从而成为独立的 AM（Access Method）。内部按职责划分为多个 .c 文件：`nbtinsert.c` 处理插入与页分裂；`nbtsearch.c` 实现前向/后向索引扫描；`nbtpage.c` 封装页面布局读写与 metapage 管理；`nbtsplitloc.c` 计算分裂点；`nbtdedup.c` 执行延迟去重（posting list）；`nbtsort.c` 负责排序辅助；`nbtcompare.c` 提供比较支持函数；`nbtutils.c` 提供通用工具；`nbtxlog.c` 定义并生成 WAL 记录用于崩溃恢复；`nbtvalidate.c` 做索引一致性校验。依赖方向单向：高层回调（nbtree.c）→ 具体操作（insert/search/page/split/dedup）→ 底层工具（utils/compare），并通过 `access/nbtxlog.h` 与 WAL 子系统交互，通过 `storage/indexfsm.h` 与 FSM 协作回收已删除页。构建由本目录 `Makefile` 声明 OBJS 列表，最终链接进后端共享库。
