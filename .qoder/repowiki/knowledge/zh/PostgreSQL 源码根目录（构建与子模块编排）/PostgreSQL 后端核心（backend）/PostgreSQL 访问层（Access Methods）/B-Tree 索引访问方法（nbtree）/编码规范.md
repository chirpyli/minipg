- 每个 .c 文件对应一个清晰职责域（插入、搜索、页面、分裂位置、去重、排序、比较、工具、验证、WAL），并通过 nbtree.c 统一暴露 IndexAmRoutine 回调。
- 对 B-Tree 页面的访问集中在 nbtpage.c 中，其他文件通过 `_bt_*` 系列函数间接读写页面，避免直接操作 Page 结构。
- WAL 相关操作在 nbtxlog.c 中集中定义与生成，插入/删除/分裂等写路径通过调用该模块记录日志以保证可恢复性。
- 公共接口命名遵循 `_bt_*` 前缀约定（如 `_bt_doinsert`、`_bt_initmetapage`），区分内部实现与对外注册的 `bt*` 回调。
- 并发控制围绕页级锁与右/左 sibling 指针进行，搜索时不持读锁仅短暂 pin，分裂/删除时按 Lehman-Yao 规则耦合父-子页锁。
