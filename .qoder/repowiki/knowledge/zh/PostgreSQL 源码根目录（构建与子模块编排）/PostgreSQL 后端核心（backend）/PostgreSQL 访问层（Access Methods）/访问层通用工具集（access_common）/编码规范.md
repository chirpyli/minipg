- 每个 .c 文件顶部包含标准版权声明、IDENTIFICATION 注释块以及 postgres.h 与相关内部头文件的 include 序列。
- 对外暴露的 API 以文件名语义命名（如 relation_open、ScanKeyEntryInitialize、CreateTupleDescCopy），并在函数注释中说明调用方内存上下文与锁持有约定。
- 对参数进行边界断言（如 Assert(lockmode >= NoLock && lockmode < MAX_LOCKMODES)、AssertArg(natts >= 0)），错误路径通过 elog(ERROR, ...) 报告。
- TOAST 压缩方法通过枚举 cmethod 的 switch 语句分派到 pglz/lz4 具体实现，未识别方法统一走 default 分支报错。
- 共享状态通过全局静态变量（如 CurrentSession、missing_cache）配合懒初始化（init_missing_cache 等）按需创建，并使用 TopMemoryContext 管理生命周期。
