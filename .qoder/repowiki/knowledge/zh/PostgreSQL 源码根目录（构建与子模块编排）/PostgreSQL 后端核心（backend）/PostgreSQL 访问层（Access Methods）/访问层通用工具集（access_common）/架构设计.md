本目录是 backend/access 下的公共工具包，由 Makefile 通过 OBJS 列表显式声明编译单元（attmap、bufmask、detoast、heaptuple、indextuple、printsimple、printtup、relation、scankey、session、syncscan、toast_compression、toast_internals、tupconvert、tupdesc），并统一 include src/backend/common.mk 以接入后端构建体系。
- 元组与描述：heaptuple.c、indextuple.c、tupdesc.c、tupconvert.c 实现 HeapTuple/IndexTuple 的构造、拷贝、缺失值缓存（基于哈希表 missing_cache）、TupleDesc 创建与复制等；依赖 access/htup_details.h、access/tupdesc_details.h 等内部头文件。
- TOAST 子系统：detoast.c、toast_internals.c、toast_compression.c 分别负责解压缩、外部存储写入/查找以及 pglz/lz4 压缩策略选择，通过 switch(cmethod) 分派具体算法。
- 扫描与关系：scankey.c 封装 ScanKeyEntryInitialize/ScanKeyInit 等扫描键初始化；relation.c 提供 relation_open/close/openrv 等关系打开/关闭入口，统一走 relcache 与锁管理。
- 会话共享：session.c 维护 CurrentSession 全局指针，通过 DSM + shm_toc + DSA 建立 per-session 共享段，用于并行查询中 leader/worker 间共享记录类型元数据注册表。
- 同步扫描与缓冲掩码：syncscan.c、bufmask.c、attmap.c 提供同步扫描与缓冲区位掩码等辅助能力。
依赖方向单向向下：本模块仅依赖 utils/、common/、storage/、catalog/ 等更底层或平级组件，不反向被同层其他 access 子目录依赖，作为被上层 heapam/indexam/tableam 等调用的基础库。
