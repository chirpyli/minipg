本模块是后端 `access/transam` 目录，按职责划分为若干相互协作的子组件：
- 事务控制层：`xact.c` 维护 TransactionStateData 栈，实现顶层事务/子事务/保存点的状态机（TRANS_* / TBlockState），并通过 `StartTransactionCommand`/`CommitTransactionCommand`/`AbortCurrentTransaction` 等接口与主循环交互。
- WAL/XLOG 层：`xlog.c`、`xloginsert.c`、`xlogreader.c`、`xlogutils.c`、`generic_xlog.c`、`timeline.c`、`xlogarchive.c`、`xlogfuncs.c` 提供 WAL 写入、插入 API（XLogBeginInsert/XLogRegister*）、读取与归档回放能力；`rmgr.c` 通过 `RmgrTable` 注册各资源管理器（heap、btree、clog 等）的 redo/desc/identify/startup/cleanup 回调，由 `rmgrlist.h` 集中枚举。
- 事务状态持久化：`clog.c` 管理 pg_xact（提交状态位图），`subtrans.c` 管理 pg_subtrans（子事务父关系），`multixact.c` 管理多事务 ID，`commit_ts.c` 记录提交时间戳；它们统一基于 `slru.c` 的 Simple LRU 共享内存页缓冲 + LWLock 并发控制访问磁盘段文件。
- 两阶段提交：`twophase.c` 与 `twophase_rmgr.c` 实现 PREPARE/COMMIT PREPARED/ROLLBACK PREPARED 及对应的 WAL 记录类型。
- 辅助设施：`varsup.c` 提供变量/序列号分配，`parallel.c` 处理并行 worker 的事务上下文传播，`transam.c` 暴露跨模块统一的 transam 初始化入口。
依赖方向自顶向下：xact → rmgr/xlog → clog/subtrans/multixact/commit_ts → slru；rmgr 仅作为注册表反向引用各 access method 的 xlog 头，不直接调用其实现。Makefile 将所有 .o 链接为同一目标，版本检查依赖 `catversion.h`。
