- 每个资源管理器（rmgr）在 `rmgr.c` 中通过 `PG_RMGR` 宏在 `RmgrTable` 里注册 redo/desc/identify/startup/cleanup 回调，新资源需同时修改 `rmgrlist.h`。
- 事务状态以分层枚举表达：底层 `TransState`（TRANS_DEFAULT/INPROGRESS/COMMIT/ABORT/PREPARE）与高层 `TBlockState`（TBLOCK_BEGIN/INPROGRESS/END/ABORT_*）分离，分别描述服务器视角与客户端查询块视角。
- 对事务相关持久化结构（pg_xact、pg_subtrans、multixact、commit_ts）统一通过 `SimpleLruInit` 注册到 SLRU 控制器，使用 `SlruCtl` + LWLock 控制锁加每缓冲锁的模式进行并发 I/O。
- WAL 记录构造遵循固定模式：`XLogBeginInsert()` → `XLogRegisterBuffer`/`XLogRegisterBufData`/`XLogRegisterData` → `XLogInsert(rmgr_id, info)` → `PageSetLSN`，并在临界区（START_CRIT_SECTION/END_CRIT_SECTION）内完成。
- 事务生命周期采用两阶段收尾：`EndTransactionBlock` 进入 COMMIT/ABORT 状态，真正的清理推迟到 `CommitTransactionCommand`/`CleanupTransaction` 执行，以便主循环继续处理后续命令。
- 所有源文件顶部包含标准 PostgreSQL 版权头与 IDENTIFICATION 注释块，并使用 `#include "access/*.h"` 形式引用同模块头文件。
