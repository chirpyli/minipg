- 每个源文件以标准 PostgreSQL 版权头与 `IDENTIFICATION` 注释开头，并在文件顶部用块注释说明该文件的职责与关键设计约束。
- 对外暴露的预处理入口函数统一接收 `PlannerInfo *root` 作为上下文，将中间结果写入 `root` 的字段（如 `processed_tlist`、`update_colnos`、`agginfos`）。
- 对解析树节点的遍历采用递归 walker 模式（如 `preprocess_aggrefs_walker`、`pull_up_sublinks_jointree_recurse`），将具体逻辑下沉到同名 `_recurse` 或 `_callback` 静态函数中。
- 通过 `nodeTag(node)` switch 分支处理不同节点类型，并对未知 tag 使用 `elog(ERROR, ...)` 报错，保证节点类型处理的完备性。
- 对 AND/OR 子句保持扁平化约定，引入 `pull_ands`/`pull_ors` 等辅助函数在局部变换后恢复扁平结构。
