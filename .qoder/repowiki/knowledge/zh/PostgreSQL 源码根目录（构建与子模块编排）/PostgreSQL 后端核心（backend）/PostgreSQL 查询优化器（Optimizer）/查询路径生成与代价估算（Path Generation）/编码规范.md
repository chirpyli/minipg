- 每个 .c 文件顶部包含标准版权声明与 IDENTIFICATION 注释块，标明文件路径与用途。
- 通过全局 GUC 变量（如 enable_seqscan、seq_page_cost、min_parallel_table_scan_size）暴露可配置的路径生成开关与代价参数。
- 路径生成函数统一接收 PlannerInfo *root 与 RelOptInfo *rel，并将生成的 Path 通过 add_path() 追加到 rel->pathlist。
- 静态内部辅助函数在文件作用域内声明并使用 set_*/make_*/get_* 前缀命名（如 set_base_rel_sizes、make_rels_by_clause_joins、get_cheapest_parameterized_child_path）。
- Join 搜索采用按 level 递增的动态规划模式，通过 root->join_rel_level[] 缓存中间结果并在每层调用 make_join_rel 生成新 rel。
