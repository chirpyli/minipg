本模块是 PostgreSQL 后端优化器的核心，按职责拆分为多个 .c 文件并通过 Makefile 统一编译：
- allpaths.c 提供顶层入口 make_one_rel()，协调 base rel 尺寸估计、pathlist 生成与 join 搜索；joinrels.c 实现基于动态规划的 join_search_one_level()，按 level 逐步构造 joinrel 并支持 bushy 计划。
- indxpath.c 将 RestrictInfo/EquivalenceClass 匹配到索引列，生成 IndexScan/BitmapScan/IndexOnlyScan 等路径；tidpath.c 处理 TID Scan；pathkeys.c 管理排序键 PathKey 的等价与合并。
- costsize.c 集中定义 seq_page_cost、cpu_tuple_cost 等 GUC 参数，并提供 estimate_*_selectivity、cost_*_join 等代价计算函数；clausesel.c 实现 clauselist_selectivity_ext() 用于 WHERE/HAVING 选择率估算；equivclass.c 维护 EquivalenceClass 以推导等价谓词。
- 依赖方向单向向上：各文件通过共享头 optimizer/pathnode.h、optimizer/paths.h、optimizer/cost.h、optimizer/plancat.h 等访问 PlannerInfo、RelOptInfo、Path 等节点，不反向依赖上层 planner/executor；Makefile 仅列出 OBJS 列表，由顶层 common.mk 完成链接。
