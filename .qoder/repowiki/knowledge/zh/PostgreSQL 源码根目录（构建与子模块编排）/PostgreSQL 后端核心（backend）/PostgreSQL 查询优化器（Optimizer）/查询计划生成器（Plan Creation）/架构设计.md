本模块是 PostgreSQL 优化器 plan 阶段的实现，按职责拆分为多个 .c 文件并通过 Makefile 统一编译：
- planner.c：外部入口 `planner()` 与上层规划协调者 `grouping_planner()`，暴露 `planner_hook`/`create_upper_paths_hook` 供插件扩展。
- planmain.c：核心 `query_planner()`，构建基表 RelOptInfo、等价类、占位符、外连接消除、分区展开，并最终调用 `make_one_rel()` 完成连接关系规划。
- createplan.c：将选定的 Path 递归转换为具体 Plan 节点（SeqScan/IndexScan/NestLoop/MergeJoin/HashJoin/Sort/Agg/Limit/ModifyTable 等），通过 `create_plan_recurse` + 各 `create_*_plan` 函数一一对应 Path 类型。
- analyzejoins.c：连接分析与代价估算辅助。
- planagg.c：聚合相关计划生成。
- subselect.c：SubLink/CTE 的 SubPlan/InitPlan 转换，使用 PARAM_EXEC 参数在父子查询间传递关联变量。
- initsplan.c / setrefs.c：初始化计划与引用修正。
依赖方向自上而下：planner → planmain → createplan；subselect/initsplan/setrefs 作为横切能力被 planner/planmain 调用；所有文件共享 optimizer/ 下的公共头（optimizer.h、pathnode.h、paths.h、cost.h、clauses.h 等），不反向依赖 executor。
