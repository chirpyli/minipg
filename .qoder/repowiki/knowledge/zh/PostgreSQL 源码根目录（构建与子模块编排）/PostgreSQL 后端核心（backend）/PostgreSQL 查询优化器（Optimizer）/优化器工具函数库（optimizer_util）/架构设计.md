本模块是 `src/backend/optimizer` 下的共享工具层，按功能主题拆分为多个独立 `.c` 文件，每个文件对应一类优化器内部数据结构或操作域：
- 表达式与子句：`clauses.c`、`orclauses.c`、`predtest.c` 提供常量折叠、聚合/窗口函数检测、布尔/OR 子句简化、谓词测试等。
- 路径与代价：`pathnode.c` 实现 `Path` 列表管理、`compare_path_costs`/`compare_fractional_path_costs` 等代价比较与支配判定。
- 关系与目录：`relnode.c`、`plancat.c` 负责 `RelOptInfo` 构建、系统目录访问、索引/统计信息提取；`joininfo.c`、`restrictinfo.c` 维护连接条件与限制条件的 Relids 信息。
- 变量与目标列：`var.c`、`tlist.c`、`placeholder.c` 提供 Var/PlaceHolderVar 抽取、别名展开、目标列重写。
- 参数与附加信息：`paramassign.c`、`appendinfo.c` 处理执行参数绑定与 Append 计划节点信息。

所有文件通过 `Makefile` 中的 `OBJS` 列表统一编译为对象文件并链接进优化器后端，依赖方向自下而上：本模块被上层 `optimizer/*.c`（如 `planmain.c`、`prep.c`、`costsize.c`）调用，自身仅依赖 `nodes/*`、`parser/*`、`utils/*`、`catalog/*`、`access/*` 等基础子系统，不反向依赖更高层的规划逻辑。各文件以头文件（位于 `optimizer/` 顶层）暴露接口，形成“按主题分文件 + 公共头文件”的扁平结构。
