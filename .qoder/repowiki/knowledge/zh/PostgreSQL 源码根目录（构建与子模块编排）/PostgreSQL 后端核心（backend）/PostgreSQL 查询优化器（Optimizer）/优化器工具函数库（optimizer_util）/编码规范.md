- 每个工具文件以标准 PostgreSQL 头部注释块开头，包含版权、IDENTIFICATION 行及简要功能说明。
- 对表达式树的遍历统一采用 `*_walker(Node *node, void *context)` 形式的回调函数，并通过 `query_or_expression_tree_walker` / `expression_tree_walker` 驱动。
- 复杂遍历操作通过局部 `typedef struct { ... } xxx_context;` 上下文结构体传递状态，避免全局变量。
- 对外暴露的公共函数集中在各自头文件中声明，内部辅助函数一律加 `static` 限定在本文件作用域。
- 涉及代价比较时使用模糊比较（fuzz factor，如 `STD_FUZZ_FACTOR=1.01`）来容忍浮点误差，并在 `compare_path_costs_fuzzily` 等函数中体现。
- 文件组织遵循“一主题一文件”原则，每个 `.c` 聚焦单一优化器概念（如 clauses、pathnode、plancat、var），并通过 `objfiles.txt` 与 `Makefile` 的 `OBJS` 列表显式注册。
