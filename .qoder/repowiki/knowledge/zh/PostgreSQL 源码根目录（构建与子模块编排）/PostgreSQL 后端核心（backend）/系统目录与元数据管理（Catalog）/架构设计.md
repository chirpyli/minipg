本模块是后端系统目录（catalog）的核心实现，围绕 `src/include/catalog/` 下的 `pg_*.h` 头文件（每个对应一个系统表）和对应的 `.dat` 数据文件组织：
- 每个系统表由一对 `pg_xxx.c`（C 层访问函数）与 `pg_xxx_d.h`（生成式结构体/宏）组成，并由 `Makefile` 中的 `OBJS` 列表统一编译。
- `genbki.pl` + `Catalog.pm` 作为构建期代码生成器，解析所有 `CATALOG(...)`、`DECLARE_*` 宏以及 `.dat` 文件，产出 `postgres.bki`（引导用二进制）、`schemapg.h`（供 relcache 等使用的 Schema 宏）以及各 `pg_xxx_d.h` 生成头，再通过符号链接安装到 `src/include/catalog/`。
- `Makefile` 中 `CATALOG_HEADERS` 的顺序决定 `postgres.bki` 中表的写入顺序，注释明确标注了 BKI_BOOTSTRAP 必须优先以及 pg_statistic 必须在 pg_statistic_ext_data 之前等隐式依赖约束。
- 运行时 C 源按职责划分：`catalog.c` 提供通用目录操作入口；`dependency.c`/`pg_depend.c`/`pg_shdepend.c` 处理对象间依赖；`indexing.c`/`index.c` 维护系统表索引；`namespace.c` 管理 schema 查找；`objectaccess.c`/`objectaddress.c` 实现对象地址解析与访问钩子；`heap.c`/`storage.c`/`toasting.c` 负责底层存储与 TOAST 行为。
- 构建产物通过 `install-data` 目标安装 `postgres.bki`、`system_constraints.sql`、`system_functions.sql`、`system_views.sql` 与 `fix-CVE-2024-4317.sql` 到数据目录，供初始化阶段使用。
