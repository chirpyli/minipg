- 每个系统表在 `src/include/catalog/` 中以 `pg_xxx.h` 头文件配合 `CATALOG(...)` 宏声明列、默认值、BKI 标志，并在同目录下以同名 `.c` 提供 C 访问实现，同时自动生成 `pg_xxx_d.h`。
- 系统表数据以 `pg_xxx.dat` 形式存放 Perl 哈希字面量行，由 `Catalog::ParseData` 解析并借助 `AddDefaultValues` 补齐缺失字段，缺失必填字段会触发硬错误。
- 索引、TOAST、外键等元信息通过 `DECLARE_INDEX`/`DECLARE_TOAST`/`DECLARE_FOREIGN_KEY` 等宏在头文件中声明，由 `Catalog.pm` 在构建期提取并写入 `postgres.bki`。
- 生成的 `schemapg.h` 以 `Schema_pg_xxx` 宏暴露每张系统表的列布局，供 relcache 等组件在运行时直接引用，禁止手工编辑该文件。
- `Makefile` 中显式维护 `CATALOG_HEADERS` 与 `OBJS` 列表，前者决定 `postgres.bki` 中表的写入顺序，后者控制编译产物，新增目录需同步更新两处。
- 构建产物采用“临时文件比较后原子替换”策略（`RenameTempFile`），仅在内容变化时才覆盖目标，避免不必要的重新编译。
