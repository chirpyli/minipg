本模块是 PostgreSQL 后端进程内实现的 libpq 协议栈（与 interfaces/libpq 客户端库分离），按职责拆分为多个独立 .c 文件并通过 Makefile 统一编译：
- pqcomm.c：定义 `PQcommMethods` 函数指针表（socket_comm_reset/flush/putmessage 等）并暴露全局指针 `PqCommMethods`，作为后端套接字 I/O 的抽象层；同时维护发送/接收缓冲、非阻塞 socket + latch 事件循环（FeBeWaitSet）。
- be-secure.c：在 pqcomm 之上封装 secure_read/secure_write，处理 EWOULDBLOCK/EAGAIN 下的 WaitEventSet 等待与 postmaster 死亡检测。
- pqformat.c：基于 StringInfo 的消息编解码（pq_beginmessage/pq_send* / pq_getmsg*），区分 raw 数据与带字符集转换的 text，供上层协议使用。
- auth.c：客户端认证入口 ClientAuthentication，当前实现为无条件信任放行（minipg 裁剪）。
- ifaddr.c：IP/CIDR 掩码计算与系统接口地址枚举（pg_range_sockaddr、pg_foreach_ifaddr）。
- pqmq.c：通过替换 PqCommMethods 将 libpq 输出重定向到 shm_mq（共享内存消息队列），用于并行 worker 与 leader 之间转发协议消息，并提供 pq_redirect_to_shm_mq / pq_set_parallel_leader 切换点。
- pqsignal.c：后端信号集初始化（BlockSig/UnBlockSig/StartupBlockSig）与 postmaster 专用 pqsignal_pm。
依赖方向单向向上：auth/ifaddr/pqmq/pqsignal → pqformat → pqcomm → be-secure；对外通过 libpq/libpq.h 暴露 Port、StringInfo、PQcommMethods 等结构体，被 tcop/postmaster/storage 等上层模块调用。
