- 通过定义一组静态函数并填充 PQcommMethods 结构体（如 PqCommSocketMethods、PqCommMqMethods），再以全局指针 PqCommMethods 指向该表，实现传输后端的可插拔替换。
- 所有网络 I/O 路径在阻塞模式下统一使用 FeBeWaitSet + ModifyWaitEvent + WaitEventSetWait 配合 MyLatch 实现可中断等待，并在等待前检查 WL_POSTMASTER_DEATH。
- 消息构造遵循 begin/send*/end 三段式 API（pq_beginmessage/pq_send* / pq_endmessage），字符串字段统一通过 pg_server_to_client 进行字符集转换后再写入 StringInfo。
- 跨平台差异通过 HAVE_* 或 #ifdef 条件编译分支处理（如 TCP keepalive 选项名、getifaddrs 接口、Windows 信号别名）。
- 每个 .c 文件顶部以块注释声明 INTERFACE ROUTINES 清单，列出对外导出的函数及其职责，作为模块契约文档。
