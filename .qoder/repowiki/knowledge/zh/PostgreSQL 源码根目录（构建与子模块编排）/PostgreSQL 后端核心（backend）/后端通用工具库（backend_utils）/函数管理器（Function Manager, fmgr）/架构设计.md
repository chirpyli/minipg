模块由三个编译单元组成：`fmgr.c` 实现 V1 函数管理接口，维护 `FmgrInfo`（函数查找结果缓存）与 `FunctionCallInfoBaseData`（调用参数/上下文），通过内置函数表 `fmgr_builtins` + OID 索引快速命中，否则查 `pg_proc` 并区分 C 语言与其他语言处理路径；`dfmgr.c` 提供动态库加载能力，基于 `dlopen/dlsym` 维护已加载共享库链表 `DynamicFileList`，对外暴露 `load_external_function` / `lookup_external_function` / `load_file`；`funcapi.c` 提供面向 SRF（set-returning function）和复合类型的便利 API，如 `init_MultiFuncCall` / `per_MultiFuncCall` / `end_MultiFuncCall`，并通过 `ReturnSetInfo` 协调 value-per-call 与 materialize 两种模式。依赖方向单向：`dfmgr.c` → `fmgr.c`（通过 `fmgr.h`），`funcapi.c` → `fmgr.c`；构建产物由 `Makefile` 指定为 `dfmgr.o`、`fmgr.o`、`funcapi.o`，并通过 `common.mk` 链接到后端。
