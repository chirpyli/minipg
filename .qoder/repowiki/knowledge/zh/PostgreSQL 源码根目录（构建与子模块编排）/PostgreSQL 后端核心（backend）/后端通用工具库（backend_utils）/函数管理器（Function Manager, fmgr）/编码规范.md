- 所有可被 SQL 调用的函数统一采用 `Datum function(PG_FUNCTION_ARGS)` 签名，并通过 `PG_FUNCTION_ARGS` 宏展开为 `FunctionCallInfo fcinfo`，便于脚本识别函数定义。
- 函数参数读取与返回值构造一律使用 `PG_GETARG_*` / `PG_RETURN_*` 宏族，自动处理 pass-by-value/pass-by-reference 及 TOAST 解压缩。
- 跨多次调用的状态保存在 `fcinfo->flinfo->fn_extra` 中，并在首次调用时于 `flinfo->fn_mcxt` 下分配专用 MemoryContext（如 `multi_call_memory_ctx`）存放长生命周期数据。
- 函数查找优先走内置函数表 `fmgr_builtins` 的 OID 索引快速路径，未命中时才回退到 `SearchSysCache1(PROCOID, ...)` 查询系统目录。
- 动态库加载前校验 `Pg_magic_struct` 魔数，并通过 `file_list` 链表去重相同文件，避免重复加载同一共享对象。
