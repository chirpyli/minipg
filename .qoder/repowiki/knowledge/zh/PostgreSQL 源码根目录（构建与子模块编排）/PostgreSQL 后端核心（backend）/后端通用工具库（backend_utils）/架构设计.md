本目录作为后端共享库的根 Makefile，按子目录（activity/adt/cache/error/fmgr/hash/init/mb/misc/mmgr/resowner/sort/time）组织功能，并通过顶层构建脚本集中生成跨子模块共享的元数据：`Gen_fmgrtab.pl` 扫描 `pg_proc.dat` 与各子模块导出的 C 符号，生成 `fmgrtab.c`、`fmgroids.h`、`fmgrprotos.h`，使 adt、cache、hash、sort、mb 等子模块实现的函数能被 fmgr 以 OID 直接查找调用；`generate-errcodes.pl` 从 `errcodes.txt` 生成 `errcodes.h` 供 error 子模块使用；DTrace probes 由 `probes.d` 经 `Gen_dummy_probes.sed` 生成 `probes.h` 并链接到 include 目录。子模块之间不直接互相依赖，而是通过统一的 `Datum`/`FmgrBuiltin`/`palloc`/错误上报等公共接口间接协作——例如 adt 中的类型函数经 fmgr 表被 cache、sort、misc 等上层组件调用，mmgr 提供所有子模块共用的内存上下文，mb 为 adt 的字符串处理提供编码转换，time 与 cache 共同支撑 MVCC 可见性判断。
