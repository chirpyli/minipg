本模块按缓存目标与职责划分为多个独立 .c 文件，由 Makefile 统一编译为共享对象：
- 失效协调中心 inval.c：维护当前命令与前一命令的失效请求链表（InvalidationChunk / InvalidationListHeader），在 CommandCounterIncrement / 事务提交时触发本地缓存刷新并通过 SI 消息队列向其他后端广播 SharedInvalidationMessage；同时管理 relcache init 文件失效标志。
- 元组级缓存 catcache.c：基于哈希桶 + 键值匹配提供通用 catalog tuple 缓存，供上层 syscache 复用。
- 系统目录缓存 syscache.c：定义 cachedesc 数组与 cacheinfo[]，将 pg_ 系统表映射为带唯一索引的 syscache 条目，是 parser/planner/executor 访问系统目录的高速通道。
- 关系缓存 relcache.c / relmapper.c / relfilenodemap.c：维护 Relation 描述符、物理文件到 OID 的映射以及 relmap 文件读写，受 relcache 失效回调驱动重建。
- 类型缓存 typcache.c：缓存 pg_type 相关元信息，供表达式与操作符解析使用。
- 计划缓存 plancache.c：缓存已解析/计划的 QueryPlan，依赖 relcat/typcat 失效通知进行选择性重规划。
依赖方向单向向下：plancache → relcache/typcache → syscache/catcache → inval；inval 通过注册回调向上通知各缓存子系统，形成发布-订阅式的失效传播边界。
