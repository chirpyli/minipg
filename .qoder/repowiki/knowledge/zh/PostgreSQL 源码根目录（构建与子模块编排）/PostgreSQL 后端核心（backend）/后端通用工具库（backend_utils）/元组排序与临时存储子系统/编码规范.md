- 每个 .c 文件顶部包含标准 PostgreSQL 版权头与 IDENTIFICATION 注释块，标明源码路径。
- 通过 SortSupport 结构（ssup_cxt、ssup_collation、comparator 等）解耦排序核心与具体数据类型比较逻辑，由 sortsupport.c 统一装配。
- 使用状态枚举（如 TupStoreStatus、LogicalTape 的 writing/frozen/dirty 标志）驱动有限状态机，而非分散的条件分支。
- 对大对象分配统一走 MemoryContext 与 ResourceOwner 管理，确保 ereport(ERROR) 时资源自动清理。
- 通过宏模板（sort_template.h 的 ST_* 宏）生成可重复使用的排序/比较代码变体，qsort_interruptible.c 即为此模式实例。
- 外部 I/O 一律经由 BufFile 抽象，logtape 内部再将其组织为逻辑 tape 链表，屏蔽底层文件系统限制。
