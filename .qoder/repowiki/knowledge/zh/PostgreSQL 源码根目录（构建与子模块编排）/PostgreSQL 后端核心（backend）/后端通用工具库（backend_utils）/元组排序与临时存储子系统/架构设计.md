本模块按职责划分为六个协作的 C 源文件，通过 Makefile 统一编译为 utils/sort 目标：
- tuplesort.c：对外主入口，封装 SortTuple 结构，依据 work_mem 在内存 qsort 与基于 logtape 的外部多路归并之间切换，支持并行排序（leader/worker 共享 tapeset）。
- sortsupport.c：SortSupport 适配器层，优先调用 opfamily 的 BTSORTSUPPORT_PROC 加速比较器，否则回退到 PrepareSortSupportComparisonShim 包装旧式 btree 比较函数。
- logtape.c：逻辑磁带抽象，将多个“逻辑 tape”映射到单个 BufFile 上并通过块链 + TapeBlockTrailer 实现空间回收，避免传统多文件合并带来的峰值磁盘翻倍。
- tuplestore.c：无排序的通用临时元组容器，状态机 TSS_INMEM/TSS_WRITEFILE/TSS_READFILE 在内存数组与 BufFile 间切换，支持多读指针、向后扫描与 truncate。
- sharedtuplestore.c：跨事务共享 Tuplestore 的扩展实现。
- qsort_interruptible.c：通过 sort_template.h 宏模板生成带 CHECK_FOR_INTERRUPTS 的可中断 qsort，供长耗时排序路径响应取消信号。
依赖方向自顶向下：tuplesort → sortsupport/logtape/tuplestore；logtape → buffile；所有文件共享 utils/memutils、storage/buffile 等基础设施。
