模块以 mcxt.c 为入口，维护全局上下文树（TopMemoryContext、ErrorContext、CacheMemoryContext、MessageContext、TopTransactionContext、CurTransactionContext、PortalContext）并通过 CurrentMemoryContext 暴露当前上下文；所有上下文对象均为 MemoryContextData，通过 methods 指针表（MemoryContextMethods）分派 reset/free/realloc/alloc 等操作，从而解耦上下文生命周期管理与具体分配策略。

- 通用上下文管理：mcxt.c 负责创建/删除/重置上下文、回调注册、统计与错误恢复（ErrorContext 保证至少 8K 可用且允许在临界区分配）。
- 默认分配器：aset.c 实现 AllocSetContext，按块（默认 8K，指数增长）分配并维护空闲链表，适合通用场景。
- 专用分配器：slab.c 提供固定大小块的 SlabContext；generation.c 提供按代（generation）批量释放的 GenerationContext；dsa.c 提供基于动态共享分配的 DSA 上下文，三者均优先将内存归还 OS。
- 辅助组件：freepage.c 管理页级空闲空间；portalmem.c 处理 Portal 相关内存；memdebug.c 提供 Valgrind/调试钩子。
- 构建：Makefile 将上述 .c 编译为静态目标文件，由上层 backend 链接；依赖 utils/memutils.h、nodes/memnodes.h 等公共头定义接口边界。
