- 每个具体分配器（AllocSet、Slab、Generation、DSA）通过填充 MemoryContextMethods 函数表并以该表指针挂载到 MemoryContextData 上，使 mcxt.c 仅通过方法指针调用具体实现。
- 分配出的 chunk 在用户可见数据之前紧接一个指向所属 MemoryContext 的指针，使 pfree/repalloc 能从任意指针反查其上下文。
- 全局顶级上下文以独立全局变量（TopMemoryContext、ErrorContext、CacheMemoryContext 等）暴露，并由 MemoryContextInit 在进程启动时集中初始化。
- 上下文通过 parent/firstchild/sibling 指针构成森林结构，reset/delete 操作沿树递归传播，确保子上下文随父上下文一并回收。
- 对超出内存的处理统一通过 elog(ERROR) 抛出异常而非返回 NULL，palloc 系列不返回空指针，调用方无需判空。
