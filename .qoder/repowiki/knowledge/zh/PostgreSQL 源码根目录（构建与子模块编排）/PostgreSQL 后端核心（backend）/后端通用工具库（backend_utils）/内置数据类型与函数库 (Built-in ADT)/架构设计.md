本目录是 PostgreSQL 后端 `utils/adt` 子系统的实现层，按数据类型和功能域组织为扁平的 .c/.o 文件集合，由 Makefile 中的 OBJS 列表统一编译并链接进后端可执行文件。
- 核心抽象：`datum.c`、`varlena.c`、`expandeddatum.c`、`expandedrecord.c` 实现 Datum 的 by-value/by-reference/varlena/toasted/expanded 对象模型以及通用拷贝/传输/大小计算；`arrayfuncs.c`、`arraysubs.c`、`arrayutils.c`、`array_expanded.c`、`array_userfuncs.c`、`array_selfuncs.c`、`array_typanalyze.c` 共同构成数组类型的完整实现（输入/输出、切片、迭代、用户自定义元素、自统计、类型分析）。
- 标量类型：每个基础类型一个文件（`int.c`、`int8.c`、`float.c`、`bool.c`、`char.c`、`varchar.c`、`date.c`、`datetime.c`、`timestamp.c`、`xid.c`、`xid8funcs.c`、`oid.c`、`name.c`、`tid.c`、`pg_lsn.c`、`regproc.c`、`enum.c`、`domains.c`、`pseudotypes.c`），通常暴露 `*_in`/`*_out`/`*_recv`/`*_send`/比较/转换等一组函数。
- 复合/扩展类型：`rangetypes.c` + `rangetypes_selfuncs.c` + `rangetypes_typanalyze.c`、`multirangetypes.c` + 对应 selfuncs/typanalyze 采用“主实现 + 自统计 + 类型分析”三件套模式；`rowtypes.c`、`domains.c`、`pseudotypes.c` 处理行类型、域和伪类型。
- 优化器集成：`selfuncs.c`、`selfuncs_geo.c` 提供 oprrest/oprjoin 选择率估计；`like_support.c`、`orderedsetaggs.c`、`intagg.c`、`mcxtfuncs.c` 等提供 planner 侧支持函数。
- 工具与格式：`ruleutils.c` 将内部查询树反序列化为 SQL 文本；`formatting.c`、`format_type.c`、`quote.c`、`encode.c`、`json_escape.c`、`ascii.c`、`numutils.c`、`genfile.c`、`dbsize.c`、`version.c`、`pg_locale.c`、`misc.c` 提供通用工具；`cryptohashfuncs.c`、`lockfuncs.c`、`pgstatfuncs.c`、`oracle_compat.c` 提供特定功能扩展。
- 依赖方向：本模块向上通过 `fmgr.h`、`funcapi.h`、`utils/builtins.h`、`catalog/pg_type_d.h` 向 catalog 注册函数 OID，向下依赖 `access/`、`optimizer/`、`parser/`、`storage/`、`common/` 等子系统，但不被这些子系统反向引用——它是被调用的底层实现层。
