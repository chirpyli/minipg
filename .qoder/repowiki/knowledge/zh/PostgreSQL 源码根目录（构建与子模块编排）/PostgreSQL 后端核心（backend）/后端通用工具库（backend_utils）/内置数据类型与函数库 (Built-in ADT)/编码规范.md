- 每个内置数据类型以独立 .c 文件组织，集中实现该类型的 input/output/receive/send、比较、转换、I/O 辅助函数，并通过 PG_FUNCTION_INFO_V1 宏配合 catalog 注册到系统表。
- 对 varlena/toasted/expanded 对象的访问统一通过 `PG_DETOAST_DATUM`/`PG_DETOAST_DATUM_COPY`、`VARATT_IS_EXTERNAL_*`、`VARSIZE_ANY` 等宏进行解包与尺寸判断，避免直接操作内存布局。
- 复杂类型（数组、范围、多范围）采用“主实现 + _selfuncs + _typanalyze”的三文件拆分模式，分别承载核心逻辑、选择率估计和类型分析钩子。
- 函数参数提取与返回值封装统一使用 `PG_GETARG_*` / `PG_RETURN_*` / `PG_FUNCTION_ARGS` 宏，错误报告使用 `ereport(ERROR, ...)` 并附带 errcode/errmsg。
- 大型源文件内部通过 static 函数与局部 typedef struct 管理状态（如 ArrayIteratorData、TextPositionState、deparse_context、VarStringSortSupport），将算法细节与对外 API 隔离。
- 文件头部遵循统一的 IDENTIFICATION 注释块（包含 Copyright、文件路径标识），并按功能用分隔注释块划分接口区域（如 CONVERSION ROUTINES、EXPRESSIONS 等）。
