- 每个编码转换对以独立子目录组织，Makefile 中只声明 NAME 与 PGFILEDESC 并 include ../proc.mk，保持构建配置一致。
- 转换过程函数统一使用 PG_FUNCTION_ARGS 宏读取参数，并通过 CHECK_ENCODING_CONVERSION_ARGS 校验源/目标编码后再调用 UtfToLocal/LocalToUtf。
- 单字节编码间的相互转换通过 conv.c 中的 local2local/latin2mic/mic2latin_with_table 等通用函数实现，仅传入对应编码的转换表指针。
- 错误处理采用 noError 标志控制：遇到无效或不可转译字符时，noError=true 则提前返回剩余长度，否则调用 report_invalid_encoding/report_untranslatable_char 抛出错误。
- 会话级转换函数缓存以 ConvProcInfo 结构体链表的形保存在 TopMemoryContext，按 (server_encoding, client_encoding) 配对查找并在事务回滚时自动恢复。
