模块分为三层：
- 顶层 C 源文件（conv.c、mbutils.c、stringinfo_mb.c、wstrcmp.c、wstrncmp.c、iso.c、win1251.c、win866.c）由 Makefile 编译为后端静态对象，其中 mbutils.c 维护会话级 ConvProcInfo 链表缓存当前 client_encoding/database_encoding/message_encoding 对应的转换函数 FmgrInfo，并通过 PrepareClientEncoding/SetClientEncoding 在事务回滚时恢复；conv.c 提供 local2local/latin2mic/mic2latin 等通用单字节编码转换原语；stringinfo_mb.c/wstrcmp.c 提供多字节安全的 stringinfo 和字符串比较。
- conversion_procs/ 下每个子目录（如 utf8_and_gbk、utf8_and_big5、euc_jp_and_sjis 等）是一个独立的共享库工程，通过统一的 proc.mk 模板构建，暴露 PG_FUNCTION 宏定义的 utf8_to_xxx / xxx_to_utf8 函数，供 pg_conversion 系统动态装载。
- Unicode/ 目录包含 Perl 脚本（UCS_to_*.pl）、convutils.pm 及大量 .map/.xml 映射表，用于从 Unicode 标准数据生成各编码的转换表，Makefile 驱动该代码生成流程。
依赖方向：conversion_procs 依赖 conv.c 提供的 UtfToLocal/LocalToUtf 等底层转换 API；顶层 C 文件不反向依赖 conversion_procs，仅通过 fmgr 接口调用已注册的转换过程。
