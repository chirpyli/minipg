- 进程级初始化函数采用 `InitXxx` 命名并以 `void` 返回，按调用顺序在 postmaster 子进程中依次执行，失败时通过 `elog(FATAL, ...)` 终止进程。
- ResourceOwner 对每类资源使用独立的 `ResourceArray` 成员（bufferarr、catrefarr、relrefarr 等），新增资源类型只需复制该模式添加新数组字段。
- 全局可访问的状态通过文件作用域静态变量 + 显式全局指针（如 `CurrentResourceOwner`、`TopTransactionResourceOwner`）暴露，避免跨模块头文件耦合。
- 资源释放路径统一通过 `ResourceOwnerReleaseInternal(phase, isCommit, isTopLevel)` 分阶段执行，commit 时锁所有权上溯到父 owner，abort 时直接释放。
- Makefile 统一采用 `subdir = ...` + include `Makefile.global` + 声明 `OBJS` + include `common.mk` 的四段式模板。
