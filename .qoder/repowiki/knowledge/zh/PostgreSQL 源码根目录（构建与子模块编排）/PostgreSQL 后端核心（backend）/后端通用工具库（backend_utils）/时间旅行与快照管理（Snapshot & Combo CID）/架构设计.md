本模块由两个相互独立但同属 time 子系统的 C 源文件组成，通过 Makefile 统一编译为 `combocid.o` 与 `snapmgr.o`。
- `snapmgr.c`：PostgreSQL 快照管理器，维护活跃快照栈（ActiveSnapshot 链表）、注册快照堆（RegisteredSnapshots pairingheap，按 xmin 排序以推进 MyProc->xmin）、以及 Current/Secondary/Catalog/Historic 等静态 SnapshotData；负责快照的创建、复制、释放、导出（pg_export_snapshot）、序列化（SerializedSnapshotData）与旧快照清理（old_snapshot_threshold）。通过 resowner 机制与 xact/sinval/procarray 等子系统协作，并暴露 SnapMgrShmemSize 等共享内存接口。
- `combocid.c`：处理 HeapTupleHeaderData 中 cmin/cmax 字段重叠问题，使用 TopTransactionContext 生命周期内的数组（comboCids）+ 哈希表（comboHash，初始大小 CCID_HASH_SIZE=100）将 (cmin,cmax) 对映射为 32 位 combo command id，提供 HeapTupleHeaderGetCmin/GetCmax/HeapTupleHeaderAdjustCmax 等 API，并在 AtEOXact_ComboCid 中随事务结束重置。
依赖方向：两者均仅向上依赖 utils/ 公共头（utils/snapmgr.h、utils/combocid.h），向下依赖 access/storage/catalog 等底层子系统，不互相包含，保持职责解耦。
