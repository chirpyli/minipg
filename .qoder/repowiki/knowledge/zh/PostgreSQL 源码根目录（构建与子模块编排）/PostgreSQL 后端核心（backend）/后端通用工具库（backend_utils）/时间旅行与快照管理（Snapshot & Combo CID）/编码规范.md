- 模块内全局状态（如 ActiveSnapshot 栈、RegisteredSnapshots 堆、comboHash、comboCids 数组）以 static 变量集中声明，仅在模块内部访问，外部通过函数 API 交互。
- 事务边界资源清理通过 AtEOXact_* 回调（如 AtEOXact_ComboCid）在事务结束时重置或释放本地分配，避免显式 pfree。
- 对外 API 在入口处使用 Assert 校验调用前提（如当前事务上下文、非 HEAP_MOVED 标记），保证只被合法场景调用。
- 快照相关结构体（SnapshotData、SerializedSnapshotData、ExportedSnapshot）采用集中定义 + 静态实例（CurrentSnapshotData/SecondarySnapshotData 等）的模式以减少重复分配。
