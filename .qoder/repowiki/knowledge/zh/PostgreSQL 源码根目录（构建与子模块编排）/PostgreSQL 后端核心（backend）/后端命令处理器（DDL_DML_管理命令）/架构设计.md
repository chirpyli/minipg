本模块是后端 `tcop/utility.c` 分派到的命令执行子层，每个 `.c` 文件对应一类 SQL 命令族（如 tablecmds 处理 CREATE/ALTER/DROP TABLE，dropcmds 集中处理 DROP，alter 提供通用 ALTER OBJECT SCHEMA 分发，view/explain/vacuum/analyze/cluster 等各自独立）。所有源文件通过 Makefile 中的 OBJS 列表统一编译并链接进后端可执行文件；依赖方向单向向下：本模块调用 catalog/*、parser/*、rewrite/*、executor/*、storage/*、utils/* 等底层子系统，自身不暴露给更上层，仅由 tcop/utility 入口按命令类型路由到对应函数（如 ExecCreateTableStmt → tablecmds.c）。各文件内部通常以 `ExecXxxStmt(ParseState*, XxxStmt*, ...)` 形式的入口函数为对外接口，并通过同名头文件（commands/*.h）导出。
