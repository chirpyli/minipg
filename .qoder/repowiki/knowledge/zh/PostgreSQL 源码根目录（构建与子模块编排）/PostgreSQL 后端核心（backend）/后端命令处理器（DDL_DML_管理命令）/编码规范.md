- 每个命令文件以标准 PostgreSQL 头部注释开头，包含 IDENTIFICATION 块标明源码路径。
- 对外入口函数命名遵循 `ExecXxxStmt(ParseState *pstate, XxxStmt *stmt, ParamListInfo params, DestReceiver *dest)` 模式，接收解析树节点并返回结果。
- 对象删除与修改统一通过 catalog/dependency.h 的 ObjectAddress/ObjectAddresses 抽象进行，再调用 performMultipleDeletions 等工具完成级联操作。
- 错误报告使用 ereport + errcode/errmsg/errhint 组合，并以 gettext_noop 包裹用户可见消息以便国际化。
- 对关系或对象的访问先通过 RangeVarGetRelid/get_object_address 解析 OID，再以 relation_open/table_open 打开 Relation，并在作用域结束时关闭，确保锁粒度最小化。
- 复杂命令（如 ALTER TABLE）采用多阶段处理模型，用静态数组/枚举（如 AT_PASS_*、AlteredTableInfo::subcmds[]）组织子命令在不同 pass 中顺序执行。
