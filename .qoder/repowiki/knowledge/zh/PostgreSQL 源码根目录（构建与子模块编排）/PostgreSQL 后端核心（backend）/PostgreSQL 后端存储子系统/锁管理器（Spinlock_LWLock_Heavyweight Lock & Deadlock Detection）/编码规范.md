- 共享内存中的锁对象（LOCK、PROCLOCK）通过 LOCKTAG/PROCLOCKTAG 的哈希值低若干位选择分区，并由对应分区的 LWLock 保护，使多分区操作无需全局锁。
- LWLock 槽位编号集中声明于 `lwlocknames.txt`，通过 Perl 脚本生成 C 头与名称映射，新增锁必须追加到末尾以保持已有槽位稳定。
- 自旋锁等待采用“快速自旋 + 随机递增 `pg_usleep` 退避 + 总尝试次数上限”的模式，并在获取后根据是否经历延迟动态调整 `spins_per_delay` 以自适应单核/多核环境。
- 条件变量统一遵循 `PrepareToSleep → Sleep/TimedSleep → CancelSleep` 三段式调用模式，并使用单线程静态 `cv_sleep_target` 跟踪当前准备睡眠的目标 CV。
- 死锁检测采用“乐观等待 + `DeadlockTimeout` 延迟触发”的策略，正常路径不执行 WFG 扫描，仅在等待超时后才进入 `CheckDeadLock`。
- 高频弱关系锁通过 PGPROC 内的 fast-path 数组缓存，仅当检测到强冲突时才回退到主锁表，以减少分区 LWLock 热点。
