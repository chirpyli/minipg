本模块按锁的粒度与用途分层组织：
- 最底层 `s_lock.c`/`spin.c` 提供硬件原子 CAS 之上的自旋锁（含自适应退避与超时），作为所有上层锁的基元。
- `lwlock.c` 基于 SysV 信号量实现轻量级读写锁（LWLock），通过 `MainLWLockArray` 中的固定槽位（由 `lwlocknames.txt` 经 `generate-lwlocknames.pl` 生成 C 头/源）分配关键全局锁；`lwlocknames.h/.c` 由文本清单代码生成，保证槽位编号稳定以兼容 DTrace。
- `condition_variable.c` 在自旋锁 + Latch 之上实现可中断的条件变量，供共享内存中跨进程同步使用。
- 核心锁表位于 `lock.c`/`proc.c`/`lmgr.c`：`LOCK` 描述每个可锁对象的持有/等待状态，`PROCLOCK` 描述每个后端对某 LOCK 的请求，二者通过哈希表组织并按 LOCKTAG 低若干位分区，每区受独立 LWLock 保护以降低争用；`LOCALLOCK` 是后端私有的去重计数结构，避免频繁访问共享表。
- `deadlock.c` 实现 waits-for 图（WFG）周期检测与“软边”队列重排，采用乐观等待 + `DeadlockTimeout` 延迟触发策略，并支持并行查询组内锁豁免。
- `predicate.c` 实现 SIReadLock 谓词锁（见 `README-SSI`），用于可串行化隔离下的快照一致性。
- 构建产物由 `Makefile` 汇总为 `OBJS`，并通过 `common.mk` 链接进后端；`check: s_lock_test` 提供自旋锁单元测试目标。
