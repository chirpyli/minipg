模块由五个协作的 C 文件组成，围绕 `storage/buf_internals.h` 中定义的 `BufferDescPadded`/`BufferTag`/`BufferAccessStrategy` 等核心结构展开：
- `buf_init.c`：通过 `ShmemInitStruct` 在共享内存中分配 BufferDescriptors、BufferBlocks、IO Condition Variables 数组以及 checkpoint 排序数组，并调用 `StrategyInitialize` 完成策略层初始化。
- `bufmgr.c`：对外暴露 `ReadBuffer`/`ReleaseBuffer`/`MarkBufferDirty` 等主入口，维护每后端私有 refcount（`PrivateRefCountArray` + `PrivateRefCountHash`），协调 I/O 等待、WAL 刷写、checkpoint 与后台 writer 交互。
- `freelist.c`：实现时钟扫描（clock-sweep）替换算法，维护 `nextVictimBuffer` 原子指针与 `firstFreeBuffer/lastFreeBuffer` 空闲链表，受全局自旋锁 `buffer_strategy_lock` 保护；同时提供 ring 式 `BufferAccessStrategy` 用于顺序扫描/VACUUM/COPY IN 的大范围一次性访问。
- `buf_table.c`：基于哈希表维护 buffer tag → buffer 索引的映射，受分区化的 `BufMappingLock`（NUM_BUFFER_PARTITIONS 个 LWLock）保护，避免单系统锁竞争。
- `localbuf.c`：为临时表提供无 WAL、无 checkpoint 的本地缓冲池，使用进程内哈希表 `LocalBufHash` 查找，复用与 freelist 相同的时钟扫描思想但无需跨进程同步。
依赖方向单向向外：本模块依赖 `storage/smgr`（磁盘 I/O）、`access/xlog`（WAL）、`postmaster/bgwriter`（后台写入）、`utils/resowner_private`（资源回收），被上层 storage/catalog/executor 调用。
