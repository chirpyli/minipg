- 共享状态统一通过 `ShmemInitStruct` 分配并在 `InitBufferPool` 中初始化，首次启动时按 NBuffers 循环设置 BufferDesc 字段、LWLock 与 ConditionVariable。
- 对 buffer header 的细粒度修改使用 per-buffer spinlock，而对 free list / victim 选择等全局状态则通过单一的 `buffer_strategy_lock` 自旋锁保护。
- buffer 访问遵循“先 pin（refcount++）再获取 content lock”的两级锁约定，读路径可仅持 shared content lock，写路径需 exclusive content lock。
- 替换策略采用时钟扫描（clock-sweep）模式：维护一个循环递增的 `nextVictimBuffer` 原子计数器，配合 usage_count 递减实现 LRU 近似淘汰。
- 针对大顺序访问场景通过 `BufferAccessStrategy` 提供 ring 式专用缓冲环（256KB 顺序扫描、16MB 批量写入），与默认策略解耦。
