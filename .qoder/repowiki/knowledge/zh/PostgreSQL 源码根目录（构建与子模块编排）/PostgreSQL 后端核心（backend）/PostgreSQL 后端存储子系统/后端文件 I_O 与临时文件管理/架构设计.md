本模块由五个独立编译单元组成，通过 Makefile 统一纳入 backend 构建：
- fd.c：核心虚拟文件描述符（VFD）层，维护 LRU 缓存池 VfdCache，将 File 抽象为索引而非真实 OS FD，提供 OpenTemporaryFile/PathNameOpenFile、pg_fsync/pg_flush_data、durable_rename/durable_unlink 等接口，并跟踪 temp_file_limit、max_safe_fds、外部 FD 占用。
- buffile.c：在 fd.c 之上实现 BufFile，以 BLCKSZ 为缓冲区粒度对多个物理临时文件进行顺序读写，支持按 MAX_PHYSICAL_FILESIZE (1 GiB) 分段扩展，从而绕过单个文件 size 限制；同时提供 BufFileCreateShared/BufFileOpenShared/BufFileAppend/BufFileTruncateShared 等共享文件集 API。
- sharedfileset.c：基于 dsm_segment 生命周期管理共享临时目录，使用 refcnt + SpinLock 实现多后端共享所有权，按 temp_tablespaces 哈希选择表空间存放，进程退出或最后一个 detach 时自动清理。
- copydir.c：提供递归目录复制 copydir/copy_file，配合 pg_flush_data 和 fsync_fname 保证持久性。
- reinit.c：启动时扫描 tablespace/base/pg_tblspc 下的未登录关系，执行两阶段 cleanup/init 恢复 init fork 到主 fork。
依赖方向单向：buffile → fd/sharedfileset；reinit → copydir/fd；copydir → fd；sharedfileset → fd/common。所有错误通过 ereport(errcode_for_file_access()) 上报，资源释放依赖 ResourceOwner/on_proc_exit/on_dsm_detach 钩子。
