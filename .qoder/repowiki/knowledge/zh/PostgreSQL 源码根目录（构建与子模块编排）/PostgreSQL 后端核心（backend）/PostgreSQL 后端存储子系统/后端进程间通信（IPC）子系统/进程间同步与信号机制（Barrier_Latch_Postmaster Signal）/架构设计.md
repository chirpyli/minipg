本模块由四个相互协作但职责独立的文件组成，共同构成后端 IPC 同步层：
- barrier.c：基于自旋锁 + ConditionVariable 实现静态/动态参与者屏障，通过 phase/elected/arrived 字段协调多阶段并行算法，支持 BarrierAttach/Detach 动态加入退出。
- latch.c：提供 WaitEventSet 抽象，统一封装 epoll/kqueue/poll/self-pipe/signalfd 等多种底层等待原语，通过 WAIT_USE_* 编译期宏选择实现；SetLatch 在信号处理路径中通过 self-pipe 或 SIGURG 唤醒 WaitEventSetWaitBlock，避免 poll/epoll 的信号竞态；同时维护 LatchWaitSet 单例供 WaitLatch 复用。
- pmsignal.c：通过共享内存 PMSignalData（PMSignalFlags[NUM_PMSIGNALS] + PMChildFlags[]）实现 postmaster 与子进程的双向信号：子进程写标志位并 kill(PostmasterPid, SIGUSR1)，postmaster 用 CheckPostmasterSignal 轮询清除；同时管理子进程槽位生命周期（UNUSED→ASSIGNED→ACTIVE/WALSENDER→ASSIGNED）及 SIGQUIT 原因广播，并通过 postmaster_alive_fds 管道检测 postmaster 死亡。
- signalfuncs.c：将上述能力暴露为 SQL 函数（pg_cancel_backend、pg_terminate_backend、pg_reload_conf、pg_rotate_logfile），负责权限校验并通过 kill/SendPostmasterSignal 执行实际信号操作。
依赖方向：signalfuncs → pmsignal/latch；latch → pmsignal（postmaster 死亡事件）；barrier 独立于其他三者，仅依赖 storage/barrier.h 定义的 Barrier 结构。
