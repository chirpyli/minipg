- 跨平台 I/O 多路复用通过 #ifdef WAIT_USE_EPOLL / WAIT_USE_KQUEUE / WAIT_USE_POLL 分支组织同一逻辑的不同实现，所有公共 API 对上层屏蔽底层差异。
- 共享状态使用 volatile sig_atomic_t 声明（如 PMSignalFlags、postmaster_possibly_dead），以便在信号处理器中安全读写而无需显式加锁。
- Barrier 等并发原语通过 SpinLockAcquire/Release 保护临界区，并使用 ConditionVariablePrepareToSleep/Broadcast 实现无忙等的等待-通知模式。
- SetLatch 等热路径先检查 is_set/maybe_sleeping 快速返回，仅在真正需要唤醒时才写入 self-pipe 或发送 SIGURG，以减少系统调用开销。
- SQL 信号函数统一通过 pg_signal_backend 内部函数封装权限检查与 kill 调用，并以 SIGNAL_BACKEND_SUCCESS/ERROR/NOPERMISSION/NOSUPERUSER 枚举返回值区分不同失败场景。
- postmaster 与子进程通信采用“写共享内存标志 + kill(SIGUSR1)”的两阶段模式，接收方在信号处理后轮询并原子清除标志，避免丢失并发信号。
