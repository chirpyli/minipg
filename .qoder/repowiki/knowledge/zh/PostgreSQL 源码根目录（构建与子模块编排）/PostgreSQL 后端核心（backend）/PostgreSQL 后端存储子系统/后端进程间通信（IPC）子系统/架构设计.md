本目录是 storage/ipc 层，所有 .c 文件通过 Makefile 中的 OBJS 列表统一编译并链接到后端二进制中，由上层 backend 启动时按需调用。各子模块围绕同一份共享内存布局协作：shmem.c/shmqueue.c/shm_mq.c/shm_toc.c/dsm*.c 提供底层共享内存分配与环形队列/TOC 表；barrier.c/latch.c/pmsignal.c/procsignal.c/signalfuncs.c 在这些内存之上实现屏障、Latch、postmaster 信号通道及 SQL 暴露的信号函数；procarray.c/standby.c 维护后端进程数组并在热备模式下协调冲突恢复；ipc.c/sinval*.c 负责进程退出清理回调与共享缓存失效消息的跨进程传播。子模块之间不直接互相包含头文件，而是通过共享内存段地址、全局结构体以及统一的信号/事件语义进行松耦合通信，Makefile 保证它们在同一镜像中被链接，从而在运行时形成完整的进程间通信栈。
