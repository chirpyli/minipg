本模块由四个文件组成两层职责：
- 退出生命周期层（ipc.c + ipci.c）：ipc.c 维护三组固定大小（MAX_ON_EXITS=20）的回调数组 on_proc_exit_list / on_shmem_exit_list / before_shmem_exit_list，通过 proc_exit() → proc_exit_prepare() → shmem_exit() 的顺序依次执行 before_shmem_exit → DSM shutdown → on_shmem_exit → on_proc_exit；同时注册 atexit(atexit_callback) 作为直接调用 exit() 的兜底。ipci.c 在 CreateSharedMemoryAndSemaphores() 中汇总各子系统 ShmemSize/Init 调用，按依赖顺序创建共享内存、LWLock、DSM、XLOG/CLOG/Buffers/Locks/PredicateLocks/ProcGlobal/InvalidationState/PMSignal/ProcSignal/Checkpointer/AutoVacuum/SnapMgr/BTree/SyncScan，并暴露 RequestAddinShmemSpace() 与 shmem_startup_hook 供加载库扩展。
- 共享缓存失效层（sinval.c + sinvaladt.c）：sinvaladt.c 维护共享 SISeg，内含大小为 MAXNUMMESSAGES=4096 的环形缓冲区 buffer[]、每个后端的 ProcState 及 minMsgNum/maxMsgNum 指针；写入走 SIInsertDataEntries（持 SInvalWriteLock 独占），读取走 SIGetDataEntries（持 SInvalReadLock 共享），两者通过 msgnumLock 自旋锁对 maxMsgNum 做内存屏障同步；SICleanupQueue() 负责回收已消费消息、触发 reset 或发送 PROCSIG_CATCHUP_INTERRUPT 给落后后端。sinval.c 提供 SendSharedInvalidMessages / ReceiveSharedInvalidMessages 高层接口，并通过 HandleCatchupInterrupt / ProcessCatchupInterrupt 将信号处理推迟到事务上下文中执行 AcceptInvalidationMessages。
依赖方向：sinval.c → sinvaladt.c；ipc.c/ipci.c 仅通过 storage/ipc.h 暴露接口，不反向依赖 sinval 内部结构。
