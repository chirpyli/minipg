- 回调注册采用固定容量数组 + 索引递增模式（on_proc_exit_index / on_shmem_exit_index / before_shmem_exit_index），达到 MAX_ON_EXITS 时报 FATAL 限制。
- 退出流程严格遵循 before_shmem_exit → DSM shutdown → on_shmem_exit → on_proc_exit 的倒序执行顺序，确保低层资源先于高层释放。
- 共享状态访问通过成对的 LWLock（SInvalReadLock/SInvalWriteLock）加自旋锁（msgnumLock）保护 maxMsgNum 读写，以保证多核下的内存可见性。
- 环形缓冲写入与读取均使用 WRITE_QUANTUM/WRITE_QUANTUM 等常量分批提交，避免长时间持有锁。
- 信号处理函数仅设置 volatile sig_atomic_t 标志并 SetLatch，实际工作延迟到非信号上下文（ProcessCatchupInterrupt）中执行。
- 共享内存初始化统一通过 *ShmemSize() + ShmemInitStruct(found) 模式，由 CreateSharedMemoryAndSemaphores() 集中编排各子系统 Init 调用顺序。
