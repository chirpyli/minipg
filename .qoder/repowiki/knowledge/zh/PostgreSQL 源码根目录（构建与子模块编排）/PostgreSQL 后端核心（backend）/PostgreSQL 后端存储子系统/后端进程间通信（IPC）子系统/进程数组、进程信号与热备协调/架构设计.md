本模块由三个相互协作的子系统组成，均位于 `src/backend/storage/ipc/` 下：
- `procarray.c`：维护共享内存中的 `ProcArrayStruct`（包含 `pgprocnos[]`、`KnownAssignedXids` 环形缓冲、`replication_slot_xmin/catalog_xmin` 等），并通过 `ProcArrayLock` 保护对活跃 XID 集合的读写；提供快照可见性边界计算（`GlobalVisState`、`ComputeXidHorizons`）和 `ExpireAllKnownAssignedTransactionIds()` 等接口，供主库与备库共同使用。
- `procsignal.c`：基于 SIGUSR1 多路复用 + 共享内存 `ProcSignalHeader`/`ProcSignalSlot` 数组实现进程间信号与屏障（barrier generation + check mask + ConditionVariable），每个后端在启动时通过 `ProcSignalInit(pss_idx)` 注册槽位并设置 PID，发送方按 BackendId 索引槽位直接 `kill(pid, SIGUSR1)`，接收方通过 `CheckProcSignal` 轮询标志位处理事件。
- `standby.c`：在热备模式下为 Startup 进程建立独立的“恢复事务环境”（`RecoveryLockLists` 哈希表跟踪事务持有的锁、`VirtualXactLockTableInsert` 占位 vxid），配合 `procarray.c` 的 KnownAssignedXids 避免 MVCC 失效；通过 GUC 参数 `max_standby_archive_delay`/`max_standby_streaming_delay` 控制冲突等待超时，并在 WAL 回放中记录 AccessExclusiveLocks 以协调主备锁状态。
依赖方向：`standby.c` 依赖 `procarray.c`（已知分配 XID 列表）和 `storage/proc.h`；`procarray.c` 与 `procsignal.c` 通过共享内存结构解耦，不直接互相调用，仅通过 `storage/proc.h`、`storage/sinvaladt.h` 等 IPC 基础设施交互。
