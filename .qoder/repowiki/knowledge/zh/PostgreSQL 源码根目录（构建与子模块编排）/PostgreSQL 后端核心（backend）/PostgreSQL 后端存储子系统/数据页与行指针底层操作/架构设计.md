本模块是 storage 子系统中面向单页（BLCKSZ）内存布局的底层实现，由三个相互独立的 C 源文件组成并通过 Makefile 统一编译为静态目标：
- bufpage.c：提供 PageInit、PageIsVerifiedExtended、PageAddItemExtended 等页头与行项管理函数，负责页面生命周期内的内容布局与完整性检查。
- checksum.c：仅作为存储层 checksum_impl.h 的薄包装，将实际 CRC 计算逻辑暴露给上层；Makefile 中通过 CFLAGS_UNROLL_LOOPS 与 CFLAGS_VECTORIZE 对该目标单独启用循环展开与向量化优化。
- itemptr.c：实现 ItemPointerData 的比较、递增、递减等轻量操作，并包含对结构体大小对齐的 StaticAssert 约束。
依赖方向单向向上：本模块依赖 storage/checksum.h、access/htup_details.h、utils/memutils.h 等公共头，不反向被同目录其他文件引用；构建产物由顶层 src/backend/common.mk 汇总链接进后端可执行文件。README 文档化了 page checksum 与 WAL CRC 的职责边界及在共享缓冲池中的失效语义。
