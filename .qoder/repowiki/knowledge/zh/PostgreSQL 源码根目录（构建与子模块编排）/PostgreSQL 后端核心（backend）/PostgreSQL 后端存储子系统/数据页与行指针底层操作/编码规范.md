- 每个 .c 文件顶部包含统一的版权声明与 IDENTIFICATION 注释块，标明源码路径与职责。
- 对外暴露的 API 通过文件名语义命名（如 PageInit、PageIsVerifiedExtended、ItemPointerEquals），参数以 Page / ItemPointer 等类型指针传递原始页或指针。
- 对关键不变量使用 StaticAssertStmt 或 Assert 进行运行时/编译时断言（如 ItemPointerData 大小为 6 字节、pageSize == BLCKSZ）。
- 可选功能通过位标志位控制行为分支（如 PageIsVerifiedExtended 的 PIV_LOG_WARNING、PIV_REPORT_STAT 标志）。
- checksum 相关代码通过 DataChecksumsEnabled() 条件判断是否启用校验，保持向后兼容未开启 checksum 的集群。
