- 每个子目录独立维护 `Makefile` 与 `objfiles.txt`，由顶层 Makefile 统一收集并链接
- 跨子模块共享的数据结构统一放在 `nodes/`，并由 `copyfuncs/equalfuncs/outfuncs/readfuncs` 实现序列化与比较
- SQL 命令处理遵循 `commands/*` 按 DDL/DML 主题拆分、调用 `executor` 与 `access_methods` 的标准分层模式
- 底层能力通过 `utils/fmgr` 函数管理器注册，使 C 函数可被 SQL 层直接调用
- 各子系统通过 `storage/lmgr` 的 LWLock/Semaphore/Latch 进行进程内同步，而非直接使用平台 API
