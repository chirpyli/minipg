- 每个执行节点类型以独立 `nodeXxx.c` 文件组织，并提供 `ExecInitXxx` / `ExecXxx` / `ExecEndXxx` / `ExecReScanXxx` 四件套标准生命周期函数。
- 扫描类节点通过定义 `Next` 与 `Recheck` 回调，再调用通用 `ExecScan(&ss, Next, Recheck)` 框架来复用扫描逻辑。
- 表达式求值统一编译为 `ExprState->steps[]` 中的 `ExprEvalStep` 指令序列，由 `ExecInterpExpr` 基于 opcode 分派执行，简单模式走 `ExecJust*` 快速路径。
- 内存分配严格遵循 per-query 上下文（`estate->es_query_cxt`）与 per-tuple 上下文（`ExprContext`）分层，每元组结束后调用 `ResetExprContext` 释放临时数据。
- 外部入口（如 `ExecutorStart/Run/Finish/End`）通过 `*_hook_type` 全局钩子变量暴露给插件扩展点，默认实现以 `standard_` 前缀命名供 hook 链调用。
- 并行相关节点实现 `ExecXxxEstimate` / `ExecXxxInitializeDSM` / `ExecXxxReInitializeDSM` / `ExecXxxInitializeWorker` 一组 DSM 同步接口以支持分布式执行。
